## 下一阶段

M4 按顺序实现：全部账单已确认且无异议 → 冻结清算快照 → 仅最终收款人确认 → 全部结清后仅房主结束 → 只读归档。沿用整数分和净额配对，但不得把 Estimate.readyForSettlement 当成“已结清”。有任何到账确认时，不允许重算覆盖旧快照。

当前测试与操作记录见 [M2/M3 验证记录](verification-m23.md)，工程默认见 [assumptions.md](assumptions.md)。
