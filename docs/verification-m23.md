## 自动化覆盖

- 协商：非多数表决、本人异议不可被代理覆盖、退出与全退出边界、代理权限、旧版本确认失效、独立方案关联任务时的权限与版本。
- 任务：认领与共同负责人、正式内容编辑权限、建议接受/拒绝、交接待接受期间保留原责任、取消交接、工作完成与共识分离、修改后关联方案待重确认。
- 行程：按日期聚合已确定方案、重叠和抵达时间冲突提醒，不自动修改时间。
- 凭证：真实图片解码、格式与大小限制、过期方案上传拒绝、非成员访问拒绝、跨任务关联拒绝、当前版本凭证门槛、预订后原内容锁定。
- 账单：记账人与付款人分离、部分成员分摊、其他相关分摊者确认、记账人不可自确认、修改金额/付款人/分摊后重新确认、过期修订拒绝。
- 异议：多个提出者独立保留、编辑不能消除异议、仅本人撤销、移出分摊集合后仍能撤销原异议。
- 金额：整数分解析、平摊尾差稳定、精确自定义合计、个人账单边界、50/20/30 三角债抵消、多组净额及转账守恒，预估排除未确认和争议账单。
- 回归：原有活动、邀请、成员授权、审计、事务回滚及跨进程一次性邀请竞争继续通过。

## 五人 HTTP 演示

`scripts/demo-m23.ts` 使用五个独立登录会话，实际创建活动、邀请和成员，再依次验证：

1. 四人确认不能覆盖 E 的日期异议；E 本人退出后才确定方案。
2. 多人负责、明确交接、工作完成与确认分离；三日方案形成行程并产生时间冲突提示。
3. 生成纯色虚构 PNG 并上传为私有凭证，将当前版本标记为已预订。
4. 800 元车票由 A/C/D/E 平摊，B 不参与；48 元饮料自定义分摊为 A 20、B 15、C 13。
5. 相关成员确认、提出异议、本人撤销；待确认的 20 元停车费不计入预估。

脚本断言已确认总额为 84800 分，待确认账单 1 笔，A 净应收 62800 分，所有成员净额之和为 0。最新演示的活动 ID 与链接写入被 Git 忽略的 `output/m23-demo.json`。

## H5 实际交互

使用 Playwright CLI 的移动端浏览器会话，执行页面操作并检查截图：

1. 从详情页切换演示身份，登录后返回原详情；活动页展示协商、任务、凭证与费用入口及计数。
2. 新建并认领“早餐采购”任务，修改正式内容到 v2；发布关联方案，仅选择 A/B，进入“不确认”分支并提交有理由的异议。
3. 通过系统文件选择上传纯色假凭证，接口返回成功；列表展示上传人、时间和方案版本。鉴权下载后可正常预览。
4. 在凭证同页复用已上传图片记账，取消 D/E 分摊并保存 A 20、B 15、C 13，共 48 元；详情关联凭证且记账人 A 没有自确认入口。
5. 切换 B 返回同一账单，经二次确认变为“已确认”；提交异议后暂停计入预估，本人撤销后恢复“已确认”，保留撤销历史。

联调修复了多根节点页面的路由属性警告、缺失详情参数导致的无效请求，以及 H5 下载读取 `Content-Disposition` 的 CORS 警告。最终账单确认、异议/撤销、图片预览会话的控制台检查为 0 errors / 0 warnings。

本地截图保存在 `output/playwright/`，包括 `m23-activity.png`、`m23-expense-confirmed.png`、`m23-image-preview-final.png`，已人工查看。图片、数据库、会话与浏览器记录不提交 Git。
