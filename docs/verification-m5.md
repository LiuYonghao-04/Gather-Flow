# M5 本地质量与演示验收

> 本文保留 M5 当时的验收范围；后续真实微信登录与模拟器事件回归见 [微信接入验证](verification-wechat.md)。

日期：2026-10-20。基于 M4 `5ea1ca2`，分支 `codex/m5`。

## 实现

- 会话缓存校验令牌格式、有效期及运行模式；401 返回登录并保留页面参数。旧身份的延迟请求不会清除新登录，普通请求及凭证上传/下载使用一致的失效处理。
- 远端视图保留已有的加载、空态和重试流程，新增身份切换竞态与失败恢复测试。
- 费用改为按活动批量查询修订、确认、异议、凭证，并通过读事务保证汇总一致性；查询数不再随账单数量增长。金额计算和业务权限保持原规则。
- `demo:m5` 用 5 个独立会话从邀请审批一直执行到只读归档，所有写入走 HTTP API。
- 配置实际 AppID 与微信项目根目录，提供官方 SDK 截图命令；保存真实微信登录/已归档活动截图。
- 补齐性能测量口径、微信运行说明、3–5 分钟讲解稿和 README。

## 实际界面核验

H5 使用 Playwright 的 iPhone 13 配置：

1. 未登录打开归档深链接，选择 A 后回到原活动。
2. 拦截归档网络请求使其失败，看到“暂时无法打开”；恢复请求并点击“再试一次”，重新显示只读归档和 ¥868.00。
3. 模拟归档接口 401，进入登录页且保留活动 ID；解除拦截并点击 A 后返回原归档。

测试中的网络失败和 401 控制台记录为有意注入，不作为未处理异常掩盖。归档截图：[H5 辅助预览](assets/h5-archive.png)。

微信开发者工具 2.01.2510290 / 基础库 3.17.4：

- CLI 已验证登录、实际 AppID 导入；首次配置缓存问题经重置文件索引、清理项目编译缓存、显式根目录及重开正式构建解决，模拟器恢复显示。
- 官方 SDK 采集了五人登录和已归档活动空间截图；用户手动点击 A，确认到达 ¥868.00 归档页。截图详见[微信演示说明](wechat-demo.md)。

## 性能与限制

最终微基准中，1,000 笔账单读取和 JSON 序列化中位数由 108.21 ms 降至 27.72 ms。详细样本、P95 和未分页的响应体积见[性能记录](performance.md)。

真实微信身份仍为明确 `501 WECHAT_NOT_CONFIGURED`；真实分享发送、真机相册及弱网上传、真机性能未验收。没有上传体验版或发布。DCloud 工具链仍有 Vite CJS / Sass legacy API 提示；官方自动化 SDK 的旧传递依赖仅用于本机开发，未进行无依据的大版本升级。

下一步需要微信真机与可访问的后端地址，逐项完成分享、照片权限、上传/预览和真实身份接入。当前本地演示不依赖 AppSecret。
